💳 Project 03: Responsive Product Pricing Cards

📌 About the Project

Responsive Product Pricing Cards is a web-based project developed as part of the InternCircle Internship Program.

The main purpose of this project is to display different pricing plans in an attractive and user-friendly way.

It includes three pricing plans: Basic, Professional, and Premium. Users can switch between monthly and yearly pricing using an interactive toggle button.

🎯 Features

- Three pricing plans: Basic, Professional, and Premium.
- Monthly and yearly pricing toggle.
- Automatic price updates.
- Responsive design for mobile and desktop devices.
- Attractive pricing card layouts.
- Hover animations and effects.
- Highlighted popular pricing plan.
- Get Started buttons for each plan.
- Interactive selection messages.
- Simple and user-friendly interface.

💰 Pricing Plans

Plan| Monthly| Yearly
Basic| ₹199| ₹1,999

🛠️ Technologies Used

- HTML5 – For creating the webpage structure.
- CSS3 – For styling and designing pricing cards.
- JavaScript – For adding interactive features and switching prices.

🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the "cards.html" file.
4. Right-click and select Open with Live Server.
5. The pricing cards will open in your browser.
6. Switch between monthly and yearly plans to see the price changes.

💻 Requirements
